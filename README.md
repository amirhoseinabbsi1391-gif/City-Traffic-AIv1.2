# City-Traffic-AIv1.2
This is a continuation of the original **City-Traffic-AIv1.2** project. However, since significant changes have been made, I am uploading it as a separate repository.

The changes include:

* **Removing the dependency on LM Studio:** Due to the slowdown in decision-making and frequent connection interruptions, LM Studio made the project difficult to run on weaker systems like mine. Therefore, from now on, I will use a learning algorithm such as **Q-learning**, which provides faster decision-making and learning while also running easily on lower-end systems.

* **Fixing some bugs in the original simulator:** Several bugs within the original simulator code have also been addressed.

Soon, I will upload another repository containing a **more accurate and complete simulator with more detailed monitoring**. After that, I will integrate it with the main project so that the project can take another step forward.
